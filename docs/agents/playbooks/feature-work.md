# Feature Work Playbook

1. Normalize the task into `tasks/ready/`.
2. Produce an execution manifest.
3. Allocate one worktree per subtask.
4. Assign `implementer` plus required skills.
5. Run validation commands before handoff.
6. Merge in manifest order.
7. If the task touches terminal lifecycle, repo transition, or practice sandbox code paths, require `terminal-integration` and the terminal e2e checks before merge.
